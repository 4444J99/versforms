Transcription

    Marks

    • struck = cancelled in the notebook; raised small text = insertion; dotted gap = illegible; dotted underline = uncertain reading.
    • Short rule = passage copied from a published work, not reproduced.

    Arrangements

    • By poem and Scatter are generated anew on each visit; the link keeps the current one. Spiral is notebook order.

    Revisions

    • Step order is an editorial reconstruction from the transcription, not a record of how the page was written. Lines assumed written top to bottom; each cancellation or insertion placed after its stanza.
    • stanza · new draft · revision · order uncertain.
    • Across drafts lines are matched by shared words: = same · ≈ changed · + new · − dropped. Highlighted words are new since the previous draft.

    Hand ↔ Font

    • Each located line crossfades to the same words set in ajp-scribbles, a typeface built from letters on these pages, at the line's measured position and x-height.

    Keys

    • Arrows pan / turn · + − zoom · 0 whole · Enter focus · [ ] versions · B journal ↔ constellation · / search · Space or Esc controls. Long-press a line or page to open it in the journal; pinch closed in the journal to return.
