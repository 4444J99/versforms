# versforms

Public site for **vers.forms**, deployed by Cloudflare Pages from `site/` (no build step).

This repository holds only what has been released. Everything here is generated by
`tools/build_public.py` in the private source repository from its release list; do not edit
`site/` by hand. Until the first poem is released the site is blank paper.
